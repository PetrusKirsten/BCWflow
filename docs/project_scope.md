# Project scope — v0.1

## MVP question

How do queue times vary by attraction, hour, day type and weather conditions, and how can these patterns support operational decision-making in a theme park?

## Included in v0.1

- Live queue-time collector.
- Raw JSON storage.
- Flattened CSV dataset.
- Weather collector for a selected date range.
- Calendar/time feature builder.
- Minimal Streamlit dashboard.

## Deferred

- NLP/reviews.
- FastAPI.
- Advanced ML models.
- Automated scraping of review platforms.
- Redistribution of third-party raw data.
